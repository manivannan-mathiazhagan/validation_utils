## `%validate_case()` macro <a name="validatecase-macro-1"></a> ######
### Macro:
    %validate_case

### Purpose:
    Execute one validation case and document its input, formatted macro call,
    execution messages, and output. Highlight variables newly added to output.

### Parameters:
- id: Validation case ID.
- description: Scenario description.
- input: Input dataset.
- output: Output dataset.
- call: Macro invocation protected with %nrstr().

### Notes:
- Executes the target macro exactly once.
- New variables are detected by comparing input and output variable names.
- Existing variables remain uncolored; new output columns are green.
- Input/output tables are separate; row-level matching is not assumed.
- Formats the call with one parameter per line when commas separate
  top-level arguments (commas inside quotes or nested parentheses are kept).
- Requires %validate_init to have opened the HTML ODS destination.

## `%validate_end()` macro <a name="validateend-macro-2"></a> ######
### Macro:
    %validate_end

### Purpose:
    Finalize the HTML validation report after all validation
    cases have been executed.

### Parameters:
- None.

### Notes:
- Call once after completing all %validate_case executions.
- Adds the final report footer.
- Closes the HTML reporting destination.
- Restores the SAS LISTING destination.
- Clears existing titles and footnotes.
- Completes the report initialized by %validate_init.

### Sample code:
~~~sas
%validate_end();
~~~

## `%validate_init()` macro <a name="validateinit-macro-3"></a> ######
/*
### Macro:
    %validate_init

### Purpose:
    Initialize a single HTML validation report for SAS macro testing.
    Configure the report title, output destination, and reporting style.

### Parameters:
- macro: Name of the SAS macro being validated.
- title: Main HTML report title
    (default: SAS Macro Validation Report).
- subtitle: Optional subtitle displayed below the macro name.
- footer: Report footer text
    (default: Validation evidence).
- output (required): Full path and filename of the HTML report.

### Notes:
- Call once before executing any validation cases.
- Creates the HTML reporting environment using the HTMLBlue style.
- Generates the report title and introductory information only once.
- Subsequent validation cases are added using %validate_case.
- Finalize the report using %validate_end.
- The output directory must already exist.
- The footer text is stored for use by %validate_end.
- An error is reported if the OUTPUT parameter is missing.

### Sample code:
~~~sas
%validate_init(
    macro=derive_vars_dtm,
    title=SAS Macro Validation Report,
    subtitle=Positive and Negative Validation Scenarios,
    footer=Run by Manivannan Mathialagan on 25Oct2026,
    output=D:\Validation\test_derive_vars_dtm.html
);
~~~
